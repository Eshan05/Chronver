# Fallback Symbols

`terminal`, `database`, `package`, and `globe` are from [Lucide](https://github.com/lucide-icons/lucide), ISC licensed. SVG bodies preserve the original paths and stroke attributes. Copyright and license notice: [../providers/README.md](../providers/README.md).

Other fallback symbols use Rune Kit's bundled glyphs. Symbols are rendered in the current theme, not downloaded at runtime.

`list-filter` is from Lucide 0.468.0, under the same ISC notice linked above.
