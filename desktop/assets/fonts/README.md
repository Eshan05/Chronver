# Geist

Unmodified static TrueType faces from Vercel's official Geist repository:
https://github.com/vercel/geist-font/tree/ef2597cfc42f4797676df105517ccc0a1cfa6569

- UI: Geist Regular, Medium, SemiBold, Bold and Italic (`fonts/Geist/ttf/`).
- Code: Geist Mono Regular, Medium and Bold (`fonts/GeistMono/ttf/`).
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`.

These fonts are compiled into the executable. No font installation or runtime
download is required. `src/fonts.rs` is shared by the native app, headless renders
and full UI tests.
