# Codicons

Unmodified `codicon.ttf` and `src/template/mapping.json` from Microsoft's
`@vscode/codicons` version `0.0.46-24`. Both files come from the same archive so
profile icon IDs and font codepoints agree. The complete mapping (including
aliases) is bundled; this is not a machine-specific icon allowlist.

- Project: https://github.com/microsoft/vscode-codicons
- Archive: https://registry.npmjs.org/@vscode/codicons/-/codicons-0.0.46-24.tgz
- Archive SHA-512 (base64): `KIDWUYxG6eh+DHRg+3G4bS487T+g1ZkLfB4HylOBbCcHsvLdfLMRM/m92DS1Ljhi8nglLr9ucwwWhHTEAC+DpA==`
- Copyright Microsoft Corporation. Icons/font: CC BY 4.0 (`LICENSE`); code:
  MIT (`LICENSE-CODE`). No changes were made to the upstream assets.

Profile IDs are inert lookup keys, never URLs or local image paths. Missing or
unknown icons use the `settings` glyph, matching VS Code's default profile icon.
No network or editor installation is needed to render these bundled icons.
