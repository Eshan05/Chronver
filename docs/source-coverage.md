## Limits From Live Checks

- Agent-browser has duplicate normalized historical versions across legacy/current tags; preserved with ambiguity warnings.
- pnpm, uv, Deno and OpenCode exceed the configured three-page GitHub history budget. Requested ranges are returned but completeness remains conservative, even when their endpoints are present.
- Some inspected releases in other projects are sparse; inspection warns, while a selected authored range can still be complete.
- Product feeds are dated product/ecosystem updates, not binary versions. Figma includes platform-specific items; Supabase's public feed includes ecosystem components as well as hosted changes.
- Single-page website profiles cannot establish undocumented historical gaps. Missing boundaries or requests older than retrieved dated history produce partial results.
- RSS/Atom and linked-document adapters have offline regression coverage but no live bundled profile in this checkpoint.
